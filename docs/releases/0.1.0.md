# srlocations 0.1.0

The first release. Tag `v0.1.0`, local only and not pushed, on the commit that holds this file.

## What it is

`srlocations` builds 3D locations as Python objects and compiles them to `sr_core.scene` documents, which the
scene-render engine draws. The release holds:

- locations, prefabs, light rigs, archetypes, checks and plugins, all resolved through one registry;
- shaded, path-traced and wireframe renders, and looks drawn as passes (Lit, Flat, Cel, Ink);
- paint over the picture with holdouts and decals, and characters cast through srstudio;
- motion, where every frame of a film is byte-identical to a still of its moment;
- the mannequin: Unity Humanoid's 55 bones and 95 muscles, with reach, holds, walks and balance. It reads poses from
  BVH, glTF and tracked points and writes BVH and GLB, skinned or rigid;
- collision at placement, including settling onto seats;
- a versioned, digest-checked catalog that can be sealed, served over loopback and fetched;
- seven published locations: airliner, flight-deck, grand-tourer, news-studio, park, park-night and starship-bridge.
  `docs/location-book.md` lists each one with its versions, pictures and known limits.

## Requirements

| | |
|---|---|
| Python | 3.10 or later |
| sr-core | pinned at commit `a85ea43` and installed from git, because it is not on PyPI (`./doctor.py` installs it) |
| scene-render engine | 0.8.0 or 0.9.0. 0.9.0 has no published binary, so `./doctor.py --no-build` installs 0.8.0 on a machine that cannot compile |
| GPU | needed for renders and for the full test suite. CI uses Mesa's software Vulkan |

## Last changes before the release

- **A held foot's heel comes off without a pop** (`a631cbf`). The ankle used to swing about 10 cm across the foot in
  one frame at heel-off, and the hips jumped 4 to 6 cm. The foot now rises in proportion. A new test refuses a held
  ankle that moves 4 cm in one frame.
- **Takes and points** (`db206ed`). `fidelity()` and `positions()` no longer add a figure's own `adjust` on top of a
  take. They now read points named for Mixamo or with a namespace. A bone pointing the opposite way now turns a full
  half turn. A head whose face points are lost for a frame keeps its last turn. 12 new tests cover these, and each one
  fails without its fix.

## Not in this release

- **The dance pipeline and its research notes.** They stay outside this repository. The pipeline is a set of research
  scripts without tests, and some of the models it uses have non-commercial terms.
- **Skinned mannequins in renders, physics, grip points, seats on more props.** "Limits" in `README.md` and "Known
  limits" in `docs/location-book.md` list these, along with the others.

## Decided

- **Licence: MIT**, as in `LICENSE`. The package depends only on sr-core. Tools that use models with non-commercial
  terms stay outside the repository.

## For the committee to decide

1. **Release with CI that has never passed?** The suite passes locally on one machine and one engine version. The
   remaining risk is a clean Ubuntu install on engine 0.8.0, which nobody has tried yet.
2. **Pushing the tag.** `v0.1.0` exists only on this machine. Pushing it makes it permanent for anyone who fetches.
3. **sr-core by commit.** Users install it from git at a fixed commit. That is reproducible, but a commit that
   disappears from GitHub breaks the install.
